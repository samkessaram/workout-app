# 04: Routines

**What to build:** The Routines screen lets the lifter edit, per Session type, the ordered list of Exercises with target sets, rep range and rest category. Starting a Session loads its Routine, and after each Exercise the app offers buttons for the remaining Routine Exercises plus Done. At close, if Exercises were skipped or added versus the Routine, ask once whether to update the Routine.

**Blocked by:** 03 Log a Session (basic)

**Status:** ready-for-agent

- [ ] A Routine can be created and edited per Session type (add, remove, reorder Exercises; set target sets, rep range, rest category)
- [ ] A new Session pre-loads the Routine for its type
- [ ] After each Exercise, buttons offer the remaining Routine Exercises and Done
- [ ] At close, a one-time prompt offers to update the Routine when the Session deviated from it
