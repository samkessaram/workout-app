# 07: Notes and confounder chips

**What to build:** Tappable note chips on a Set or Exercise: tight hips, shaky, form broke down, left/right side failed first, felt easy, felt heavy. Confounder chips: poor sleep, ill, travel, missed food, injury. The lifter can add custom chips in Settings. Optional free text exists but is never required. Notes are recorded as the lifter chose them, with no diagnosis.

**Blocked by:** 03 Log a Session (basic)

**Status:** ready-for-agent

- [x] Note and confounder chips can be attached to a Set or an Exercise in one tap
- [x] Custom chips can be added and removed in Settings and appear in the picker
- [x] Optional free text can be added but nothing requires it
- [x] Confounder chips are stored in a form the coaching engine can read
